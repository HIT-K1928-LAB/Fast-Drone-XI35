# Fast-Drone-XI35

本项目是集成了视觉/激光SLAM定位、规划、控制的无人机自动飞行完整系统

## 快速开始

### 编译代码

在项目主目录运行脚本

./tools/make.sh all 编译所有包
./tools/make.sh all -c 编译所有包同时生成compile_command.json,给clangd实现代码跳转


这里写新的编译、配置和启动流程。
