终端 1：启动 rspx4

cd ~/Fast-Drone-XI35
source devel/setup.bash
sh shfiles/rspx4.sh

终端 2：启动 kf_fusion

cd ~/Fast-Drone-XI35
source devel/setup.bash
sh shfiles/kf_fusion.sh
终端 3：确认关键 topic

source ~/Fast-Drone-XI35/devel/setup.bash

rostopic hz /camera/infra1/image_rect_raw
rostopic hz /camera/depth/image_rect_raw
rostopic hz /camera/infra1/camera_info
rostopic hz /vins_fusion/extrinsic
rostopic hz /kf_fusion/kf_imu_odom
如果这些都有频率，再启动 YOLO。

终端 4：启动 YOLO 3D 目标点节点

cd ~/Fast-Drone-XI35
source devel/setup.bash
roslaunch yolo_trt_detector yolo_trt_detector.launch
终端 5：查看输出

source ~/Fast-Drone-XI35/devel/setup.bash

rostopic echo /yolo_trt/target_point
看输出频率：

rostopic hz /yolo_trt/target_point
看检测图：

rqt_image_view /yolo_trt/annotated_image
如果要先列出来核对 topic：

rostopic list | grep -E "infra1|depth|extrinsic|kf_imu_odom|target_point

rostopic echo /yolo_trt/target_point
